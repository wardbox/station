I've recently started using Matt Pocock's skills workflows to build out a greenfield pet rescue project and retrofitting a few other pre-existing projects. The main gain is the grilling skill, feels like I'm getting a deeper grasp back on my work and handing off less decision making to AI which has been my main issue with AI in the first place.

Skills are here, and I pretty much just run the setup skill and go from there with `/ask-matt` making sure I'm utilizing whatever I can. Will probably update as I go, for now using pretty much what's published and may fit in a few of my own skills within the flow. I already have a `/babysit-coderabbit` skill which I add on to the end of `/implement` which just polls the PR for a finished coderabbit review, implements fixes, then loops on that.
